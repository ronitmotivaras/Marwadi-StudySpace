<h1>Marwadi StudySpace</h1>

<p>
Marwadi StudySpace is a student discussion and Q&A web platform inspired by Stack Overflow, 
designed for students and instructors to ask questions, share answers, and collaborate in a learning environment.
</p>

<p>
This platform allows students to post questions, receive answers from peers or instructors, 
and interact through comments and likes.
</p>

<br>

<h2>Features</h2>

<h3>Main Web Module (Students & Instructors)</h3>
<ul>
  <li>User Registration & Login</li>
  <li>Dashboard</li>
  <li>Ask Questions</li>
  <li>View Questions</li>
  <li>Answer Questions</li>
  <li>Comment on Answers</li>
  <li>Like Comments</li>
  <li>View User Profiles</li>
</ul>

<h3>Admin Module</h3>
<ul>
  <li>Admin Login</li>
  <li>Add Users (Students/Instructors)</li>
  <li>Update User Information</li>
  <li>Delete Users</li>
  <li>Manage Platform Users</li>
</ul>

<br>

<h2>Tech Stack</h2>
<ul>
  <li><b>Frontend:</b> HTML, CSS, JavaScript</li>
  <li><b>Backend:</b> PHP</li>
  <li><b>Database:</b> MySQL</li>
  <li><b>Server Environment:</b> XAMPP</li>
</ul>

<br>

<h2>How It Works</h2>
<ol>
  <li>Students log in to the platform.</li>
  <li>They can ask academic questions.</li>
  <li>Other students or instructors can answer.</li>
  <li>Users can comment on answers and like comments.</li>
  <li>Admin manages all users through the admin panel.</li>
</ol>

<br>

<h2>Database Setup</h2>
<p>The project includes the MySQL database file.</p>

<ol>
  <li>Open XAMPP and start <b>Apache</b> and <b>MySQL</b>.</li>
  <li>Open <b>phpMyAdmin</b>.</li>
  <li>Create a new database.</li>
  <li>Import the provided <code>.sql</code> file into the database.</li>
  <li>Update the database name in the PHP configuration file if needed.</li>
</ol>

<br>

<h2>Installation & Run Locally</h2>

<ol>
  <li>Install XAMPP.</li>
  <li>Copy the project folder into:<br><code>C:\xampp\htdocs</code></li>
  <li>Start Apache and MySQL from XAMPP.</li>
  <li>Import the database as explained above.</li>
  <li>Open your browser and run:<br><code>http://localhost/your-project-folder-name</code></li>
</ol>

<br>

<h2>Purpose of the Project</h2>
<p>
This project was created to provide a dedicated academic discussion space for students of Marwadi University, 
where knowledge sharing becomes easy and interactive.
</p>
